# Representasi Perempuan dan Stereotip Feminitas

Presentasi web interaktif **Kelompok 1** untuk mata kuliah **Kajian Gender dan Perempuan Jepang** dengan tema **Handwritten Paper** (7 slide, Bahasa Indonesia).

- **URL Publikasi**: https://fzz90.github.io/genderkel1/
- **Objek Kajian**: Adegan Mahiru Shiina menyiapkan makanan untuk Amane Fujimiya dalam anime *Otonari no Tenshi-sama*

## Struktur 7 Slide
1. **Sampul**: Identitas mata kuliah, topik, objek kajian, dan daftar anggota Kelompok 1.
2. **Pertanyaan 1**: Apa yang ditampilkan dalam adegan? (Alur adegan interaktif & praktik *ongaeshi*).
3. **Pertanyaan 2**: Bagaimana karakter perempuan, laki-laki, atau *queer* direpresentasikan?
4. **Pertanyaan 3**: Norma gender apa yang muncul? (Peta konsep interaktif *ryousai kenbo*, *ongaeshi*, dan peran domestik).
5. **Pertanyaan 4**: Apakah adegan memperkuat atau menantang norma gender? (Termasuk perspektif anime Jepang yang melanggengkan stereotip feminin).
6. **Pertanyaan 5**: Apa bukti visual yang mendukung interpretasi kelompok? (Papan sketsa observasi visual interaktif 3 pin).
7. **Penutup**: Sintesis temuan utama dan ajakan diskusi kelas.

## Fitur Utama
- Navigasi keyboard lengkap (`←` / `→` / `Space` / `Home` / `End` / `G` / `Z` / `F` / `Esc`) dan swipe layar sentuh.
- **Glosarium Istilah (`G`)**: Panel istilah kunci Kajian Gender & budaya Jepang dengan filter kategori dan pencarian.
- **Kaca Pembesar Kursor (`Z`)**: Lensa pembesar 2x yang mengikuti kursor atau sentuhan saat presentasi di proyektor.
- Komponen interaktif di Slide 2 (tab alur adegan), Slide 4 (peta konsep klik-untuk-inspeksi), dan Slide 6 (pin bukti visual).
- Responsif di layar lebar 16:9, laptop kecil, tablet, ponsel, serta siap cetak / ekspor PDF.

## Deploy ke GitHub Pages
1. Buat repository GitHub bernama **`genderkel1`** di akun `fzz90`.
2. Push isi folder proyek ini ke branch `main`.
3. Di **Settings -> Pages**, pilih **Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` akan otomatis memublikasikan situs ke `https://fzz90.github.io/genderkel1/`.
